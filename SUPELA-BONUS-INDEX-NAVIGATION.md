
---

### **Parcours 2: Correction Mineure (Typo) — 15 min**

```
1. Valider: Checklist 2A (Maintenance v1.0) — 3 min
   └─ Vérifier que c'est bien une typo (non modification sémantique)
   
2. Créer branche: git checkout -b maintenance/v1.0-typo-[description]
   └─ Suivre convention naming
   
3. Appliquer correction typo
   └─ Test: git diff → Zéro perte contenu?
   
4. Commit (Template + Template Message 2A) — 2 min
   └─ Article 3.2 conforme documenté dans message
   
5. Push + PR → Copilot approval
   └─ 1 approbation suffisante (voie légère)
   
✅ RÉSULTAT: Typo corrigée, v1.0.x patch incrémenté
```

---

### **Parcours 3: Ajouter Documentation v1.1+ — 45 min**

```
1. Valider: Checklist 2B (Extension v1.1) — 3 min
   └─ Vérifier que modification n'est PAS constitutionnelle
   
2. Créer branche: git checkout -b feature/v1.1-[nom-artefact]
   └─ Suivre convention naming
   
3. Créer nouvel artefact Tier 2 (Template 3A) — 20 min
   └─ Copy/Paste Template, remplir sections
   └─ Vérifier Article 3 (6 règles)
   
4. Enregistrer REGISTRE-TRACTABILITE — 2 min
   └─ Nouvel item horodaté (ID + Tier + Author + SHA)
   
5. Commit + Horodatage REGISTRE — 3 min
   └─ Utiliser Template Message 2B
   
6. Push + PR → Copilot review
   └─ Vérification Article 3 + Registre
   
7. Merge + Tag v1.1-rc1 (si première extension)
   └─ Pas de release tag tant que v1.2+ non-complete
   
✅ RÉSULTAT: Nouvel artefact Tier 2 enregistré, v1.1-rc[N] créée
```

---

```

5. Si opposition:
   └─ Rejeter modification
   └─ Documenter dans ROADMAP
   └─ Continuer avec v1.1+ extensions
   
✅ RÉSULTAT: v2.0 créée (si unanime) ou rejet (si opposition)
```
