# Skill `web-fullstack`

1. Appliquer un typage strict bout-en-bout (contrats JSON / schémas Draft 2020-12 entre frontend et API).
2. Séparer état client, transport réseau et validation serveur ; ne jamais promouvoir un état UI optimiste en vérité persistée sans accusé serveur.
3. Vérifier l'accessibilité sémantique (ARIA, contraste, navigation clavier) et l'absence de secrets exposés côté navigateur.
4. En contexte `omega-zero-4d`, consommer exclusivement les endpoints et schémas validés (via MCP `omega-zero-mcp` ou CLI) et indexer tout nouveau fichier dans `INDEX_CONSTITUTION.md` (`A12`).
