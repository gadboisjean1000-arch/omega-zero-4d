# Calendrier d'exécution (8–12 semaines)

## Planning semaine par semaine
| Semaine | Jalons clés | Responsable principal | Dépendances |
|---|---|---|---|
| S1 | Kickoff institutionnel + validation scope audit | PM Gouvernance | Mandat v1.0 validé |
| S2 | Contractualisation auditeur principal + réserve | Direction + Juridique | RFP finalisé |
| S3 | Lancement audit externe (lot 1) | Auditeur principal | Accès artefacts |
| S4 | Revue comité externe #1 + premiers écarts | Comité externe | Rapport intermédiaire |
| S5 | Remédiations prioritaires (sécurité/gouvernance) | Leads techniques + conformité | Liste écarts |
| S6 | Exercice Red Team trimestriel | Red Team lead | Playbooks approuvés |
| S7 | Audit externe (lot 2) + contre-vérification | Auditeur principal | Correctifs S5-S6 |
| S8 | Décision de gate intermédiaire (`PROVISIONAL` ou `SIGNED`) | Comité externe | Registre mis à jour |
| S9 | Finalisation preuves cryptographiques | Auditeurs + sécurité | Clés/signatures |
| S10 | Benchmark officiel ISO/NIST/EU | Conformité | Données consolidées |
| S11 | Pré-clôture + revue comité #2 | Comité externe | Rapport final draft |
| S12 | Décision finale `VERIFIED_TIER2` + publication | Sponsor institutionnel | 2 signatures vérifiées |

## Risques et mitigations
| Risque | Impact | Mitigation |
|---|---|---|
| Retard auditeur principal | Décalage planning | Activation plan B sous 48h |
| Signature non vérifiable | Blocage statut VERIFIED | Pré-enrôlement clés + test J-7 |
| Quorum non atteint | Décision invalide | Calendrier verrouillé + suppléants |
| Redaction excessive | Perte de confiance publique | Comité validation redaction |
