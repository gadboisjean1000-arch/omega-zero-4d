📝 Note Méthodologique — Approche Non-Exclusive

                
L'approche SUPELA est non-exclusive : la complémentarité paradigmatique est une force, non une incohérence. Les méthodes preuve-centrées (CI/KPI/Gates) et discursives (CVEA/post-mortems/jalons J1–J4) se renforcent mutuellement. Les phases 3 (pilotage) et 4 (grande échelle) prépareront l'intégration de modèles IRT avancés (Rasch, CFA) dans la version v1.3.0. Le présent onglet constitue le Tableau Opérationnel de Validation (TOV) de référence pour l'ensemble de l'écosystème SUPELA.

                

                    Non-exclusive
                    Complémentarité paradigmatique
                    v1.3.0 → Rasch / CFA intégrés
                    Phase 3–4 : Pilotage → Grande Échelle
